# Freelance-Manager

Freelance Manager is a simple tool that helps freelancers manage their work. It keeps everything organized and easy to access.

## Features

- Add new projects
- Add clients for each project
- Add tasks inside any project
- See all work in one place
- Invoice generator is coming soon

## How to Use

- Open the app
- Add a project
- Add the client linked to that project
- Add tasks under that project
- View and manage your work easily
